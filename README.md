## 🌟 Highlights

**MR Music** is a high-performance, modern music player crafted with **Material 3 Expressive** design, dynamic color matching, and studio-grade sound processing.

| 🎨 **Design & UI** | 🎵 **Studio Audio Engine** |
| :--- | :--- |
| **Material You:** Dynamic theming matching your system wallpaper. | **Pro Audio:** Media3 high-resolution lossless playback. |
| **Expressive Controls:** Fluid animations & customizable player styles. | **10-Band Equalizer:** Precision tuning with Bass Boost & Virtualizer. |
| **Clean Aesthetics:** Neon visualizer and custom monogram branding. | **Lossless Decoders:** Support for FLAC, ALAC, WAV, AAC, and MP3. |

| 🎤 **Smart Features** | 🔒 **Privacy & Freedom** |
| :--- | :--- |
| **Synced Lyrics:** Real-time synchronized lyrics with word highlighting. | **100% Private:** Zero telemetry, no trackers, no ads. |
| **MR Music Widgets:** Custom interactive widgets for your home screen. | **Fully Offline:** Works seamlessly without internet connectivity. |
